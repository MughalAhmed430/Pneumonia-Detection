About CheXNet Architecture & Localization

CheXNet is a 121-layer Dense Convolutional Network (DenseNet-121) trained on the NIH ChestX-ray14 dataset comprising 112,120 frontal-view chest radiographs from 30,805 unique patients.

Key Architectural Highlights

  • Dense Connectivity: Direct connections from each layer to all subsequent layers ensure maximum information and gradient flow across deep feature hierarchies.
  • Global Average Pooling + Linear Layer: Replaces traditional dense classification layers with a 1024-dimensional feature vector, drastically reducing overfitting risk.
  • Multi-Label Sigmoid Activation: Outputs independent probability estimates for each of the 14 non-mutually exclusive thoracic pathologies.
  • Class Activation Mapping (CAM): Uses the final convolutional feature maps before global pooling, weighted by the linear classifier weights for class $c$, to produce interpretable pixel-level pathology heatmaps.
